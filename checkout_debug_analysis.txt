DEEP DEBUGGING ANALYSIS: Checkout & Payment Process

1. IDENTIFIED BUG:
The core reason why clicking the "Confirm Order" (.order_btn) button does absolutely nothing (no network requests, no modals, no errors) is due to a missing event listener.
- Previously, the logic for `.order_btn` (including the AJAX `fetch` request to `/checkout/process`) was located in the file `Js/pyment.js`.
- In `app/Views/pages/payment.php`, the script inclusion was recently changed from `<script src="/Js/pyment.js"></script>` to `<script src="/Js/payment.js"></script>`.
- The newly loaded `Js/payment.js` handles the address modal and `.send_btn` logic correctly, but it completely lacks the event listener for `.order_btn`. Because no JavaScript is listening for the click event, the button click is silently ignored.

2. LOCALSTORAGE JSON PARSING RISKS:
In `payment.js` (line 5), the code executes:
`let cartItems = JSON.parse(localStorage.getItem("cards")) || [];`
If `localStorage.getItem("cards")` contains an invalid or corrupted JSON string (e.g. from an interrupted save), `JSON.parse` will throw a synchronous `SyntaxError`, completely halting all script execution. This would break all JavaScript on the checkout page before the user even interacts with anything.

3. DOM SEQUENCE & ADDRESS VALIDATION CONFLICT:
In the old `pyment.js`, it checked if the user entered an address using `if (addressDiv.innerHTML === "")`. However, in the new `payment.js`, the address div is populated with a placeholder instantly on load. Therefore, the old check would fail, allowing the user to checkout without an address. The new fix resolves this by checking specifically for the generated `user-Address` element.

4. PROPOSED FIX:
Since `payment.js` is the currently loaded script, you need to add the `.order_btn` event listener and the checkout AJAX logic into `Js/payment.js`. Additionally, you should wrap the `JSON.parse` in a `try...catch` block to ensure safety.

Please add the following code into your `Js/payment.js` file (preferably inside the main `DOMContentLoaded` listener):

// --- SAFE JSON PARSING FOR CART ---
let cartItems = [];
try {
    const stored = localStorage.getItem("cards");
    if (stored) {
        cartItems = JSON.parse(stored);
    }
} catch (error) {
    console.error("Failed to parse cart items from localStorage:", error);
    cartItems = [];
}

// --- CHECKOUT SUBMISSION LOGIC ---
let orderBtn = document.querySelector(".order_btn");

if (orderBtn) {
    orderBtn.addEventListener("click", () => {
        // Ensure the address form was completed by checking if the user-Address element exists
        let userAddressEl = document.getElementById("user-Address");
        if (!userAddressEl || userAddressEl.textContent.trim() === "") {
            let modal = document.querySelector(".container_modal");
            let layer = document.querySelector(".layer");
            if (modal && layer) {
                modal.classList.add("modal_active");
                layer.classList.add("layer_active");
            }
            return;
        }

        if (!cartItems || cartItems.length === 0) {
            alert("عربة التسوق فارغة!");
            return;
        }

        const formData = new FormData();
        const csrfToken = document.querySelector('meta[name="csrf-token"]')?.getAttribute('content') || '';
        formData.append("csrf_token", csrfToken);
        formData.append("ajax_checkout", "1");
        formData.append("full_name", document.getElementById("user-Address").textContent);
        formData.append("phone", document.getElementById("phone-Address").textContent);
        formData.append("address_line1", document.getElementById("street-Address").textContent);
        formData.append("address_line2", document.getElementById("unity-Address").textContent);
        formData.append("city", document.getElementById("city-Address").textContent);
        formData.append("governorate", document.getElementById("boycott-Address").textContent);
        formData.append("zip_code", document.getElementById("postal-Address").textContent);
        
        let finalPrice = window.cartTotalValue || window.localStorage.getItem("total_Price");
        if (typeof finalPrice === 'string') {
            finalPrice = finalPrice.replace(/[^\d.]/g, '');
        }
        formData.append("total_price", finalPrice || 0);

        // Sanitize cart quantities for the backend
        formData.append("products", JSON.stringify(cartItems.map(item => { 
            item.number = parseInt(item.number || item.quantity || item.qty || 1); 
            return item; 
        })));

        // Disable button to prevent double-clicks
        orderBtn.disabled = true;
        orderBtn.textContent = "جاري التنفيذ...";

        fetch("/checkout/process", {
            method: "POST",
            headers: {
                'X-Requested-With': 'XMLHttpRequest',
                'X-CSRF-TOKEN': csrfToken
            },
            body: formData
        })
        .then(async res => {
            const text = await res.text();
            try {
                const data = JSON.parse(text);
                if (data.success) {
                    localStorage.removeItem("cards");
                    window.location.href = data.redirect || '/my-orders';
                } else {
                    alert("حدث خطأ أثناء تسجيل الطلب: " + (data.error || ""));
                    orderBtn.disabled = false;
                    orderBtn.textContent = "تأكيد الطلب";
                }
            } catch (e) {
                console.error("Server response:", text);
                alert("فشل استجابة السيرفر. راجع الكونسول (F12) لمعرفة السبب.");
                orderBtn.disabled = false;
                orderBtn.textContent = "تأكيد الطلب";
            }
        })
        .catch(err => {
            alert("حدث خطأ في الاتصال: " + err.message);
            orderBtn.disabled = false;
            orderBtn.textContent = "تأكيد الطلب";
        });
    });
}
